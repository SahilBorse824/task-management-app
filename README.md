# TaskFlow – Task Management Application

TaskFlow is a basic full-stack task management web application developed as part of an internship assignment. It allows users to register, log in, and create, manage, update, and track their tasks.

## Features

- User Registration
- User Login and Logout
- User Authentication
- Create Tasks
- View Tasks
- Edit/Update Tasks
- Delete Tasks
- Mark Tasks as Completed
- Task Priority
- Task Due Date
- Task Status Tracking
- Task Statistics
- Responsive Design
- SQLite Database
- REST API Integration

## Technologies Used

### Frontend
- HTML5
- CSS3
- JavaScript

### Backend
- Node.js
- Express.js
- Express Session
- CORS

### Database
- SQLite
